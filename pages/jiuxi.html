JiuXi Mindscape — AI Conversation Service

Voice-enabled avatar chat for on-site cultural tours with Push-to-Talk ASR, multi-provider fallbacks, and animated avatar cues.

Engineered as the interactive voice narrator and concierge interface for cultural exhibition tourism (Chinese, English, Malay). The single-page application features push-to-talk voice interactions, iFLYTEK WebSocket services with Web Speech API browser fallbacks, configurable REST LLMs, and an offline Mock Mode for zero-credential demonstrations.

// Conversation UX State Machine

4-Phase Avatar State Machine

Dynamic visual feedback states provide conversational cues for on-site visitors.

PHASE 01 // IDLE

Attract Loop

Ambient idle animation loops smoothly while awaiting visitor text or push-to-talk microphone trigger.

State: Idle Animation
PHASE 02 // LISTENING

Push-to-Talk ASR

Visitor holds microphone button; real-time audio streams via iFLYTEK WebSocket or Web Speech API fallback.

State: Listening
PHASE 03 // THINKING

REST LLM Context

Transcribed query is merged with selected persona profiles and knowledge JSON for grounded narrative generation.

State: Thinking
PHASE 04 // TALKING

TTS Speech Stream

Synthesized voice streams back with mouth movement cues, with automatic recovery on completion.

State: Talking

// Multi-Provider Speech Fallbacks

Exhibition environments require extreme fault tolerance where cloud speech endpoints can experience credential limits or network throttling.

✓ Primary provider: iFLYTEK WebSocket services for high-fidelity ASR and TTS.

✓ Automatic browser fallback: Web Speech API for recognition and SpeechSynthesis for audio.

✓ Push-to-Talk microphone flow eliminates ambient crowd speech interference.

// Exhibition Resilience & Mock Mode

On-site cultural tour demonstrations need instant readiness without waiting for API keys or cloud configurations to be established.

✓ Engineered zero-credential offline Mock Mode for instant exhibition demos.

✓ In-app settings modal with secure localStorage persistence and key masking.

✓ Dynamic avatar state cues (idle, listening, thinking, talking, issue) for visitor feedback.
