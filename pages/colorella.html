SYSTEM ARCHITECTURE #4 · EVENT & AUDITING Student Representative Council (SRC) · Raffles University

Colorella Event — Ticketing & Finance Management System

Custom desktop system synchronizing Google Sheets API, managing tiered ticket quotas, and validating payment approval workflows.

As SRC Treasurer, I designed this desktop application for the Colorella festival to replace error-prone manual spreadsheets. Built with Python and Tkinter using multi-threaded asynchronous workers, the system automated registration data ingestion, enforced tier capacity limits, and streamlined live event check-in while ensuring complete financial transparency.

// Production Interface

System UI & Check-In Console

Colorella desktop management console featuring live participant filtering, tiered ticket capacity tracking, receipt attachment inspection, and one-click check-in.

// Automated Ingestion

Google Forms Ingestion & Deduplication

Automatically pulls new attendee submissions from Google Forms responses into local memory using the Google Sheets API and pandas, verifying payment slips and resolving duplicate student IDs.

✓ Background polling threads prevent desktop UI freezing

✓ Dynamic tier caps (Early Bird, Standard, VIP) enforce hard quota limits

✓ In-memory caching for rapid participant searching during check-in

// Operational Governance

Payment Approval & Attendance Gate

Streamlined the operational duties of event treasurers, allowing instant verification of transaction reference slips and providing a 1-click on-site QR check-in workflow on event day.

✓ One-click approval / rejection status written back to shared cloud sheets

✓ Real-time attendance percentage monitor for venue capacity tracking

✓ Replaced multi-sheet manual auditing with a unified audit log
